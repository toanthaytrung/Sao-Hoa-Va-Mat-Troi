Sao Hỏa: T ≈ 1.88 năm, a ≈ 1.524 AU.
1.88² / 1.524³ ≈ 1.00 ✓
📌 Áp dụng bài toán:
a = 227.9 triệu km, b = 226.9 triệu km
c = √(a²−b²) ≈ 21.326 triệu km
dmax = a + c ≈ 249.226 triệu km ✓
